# Zenith 天顶剑（泰拉瑞亚）

> ⚠ **必须安装 REPENTOGON（忏悔龙）才能使用！** 没有 REPENTOGON 时，本 mod 的大部分功能都无法工作。
>
> ⚠ **Requires REPENTOGON!** Most features will not work without it.

《以撒的结合：忏悔+》mod。把泰拉瑞亚的终极武器“天顶剑”作为全新的 4 级被动道具加入以撒：射击键推动准星，飞剑沿泰拉原版的椭圆轨迹连续飞向准星，带拖尾、残影、受击音效和伤害数字，并与硫磺火、科技系、胎儿博士、妈刀、英灵剑、卢多维科等大量道具联动。

**Steam 创意工坊（推荐，订阅后自动更新）：** https://steamcommunity.com/sharedfiles/filedetails/?id=3822358583

## 前置

- **REPENTOGON（忏悔龙）——必须安装**
- DLC：忏悔+（Repentance+），以及之前的全部 DLC
- 推荐：External Item Descriptions、Mod Config Menu

## 手动安装

1. 下载本仓库（Code → Download ZIP，或在 Releases 里下载 `zenith.zip`）
2. 把 `mod` 文件夹复制到游戏的 `mods` 目录，并改名为 `zenith`
   （例如 `...\steamapps\common\The Binding of Isaac Rebirth\mods\zenith`，里面直接是 `metadata.xml` 和 `main.lua`）
3. 已经订阅了创意工坊版本的话，不要再手动安装，否则会加载两份

手动安装的版本不会自动更新，有新版本时需要重新下载替换。

## 使用

- 道具出现在天使房、恶魔房、宝箱房、商店（可在 Mod Config Menu 里按 L 打开“天顶剑”页面修改道具池和画面、音量设置）
- 控制台输入 `zenith_give` 直接获得天顶剑（`zenith_give 1` 给 2P）。道具编号会随其他 mod 变化，不要用 `giveitem` 加编号

## English

Terraria's Zenith joins The Binding of Isaac: Repentance+ as a new quality 4 passive item. Fire keys move a crosshair; swords fly to it in Terraria's original elliptical paths. Synergies with Brimstone, the Technology family, Dr./Epic Fetus, Mom's Knife, Spirit Sword, Ludovico and many more, all described in EID.

- **Requires REPENTOGON** and the Repentance+ DLC
- Install: subscribe on the [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3822358583), or copy the `mod` folder into the game's `mods` folder and rename it to `zenith`
- Console: `zenith_give` gives the item
